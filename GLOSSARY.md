# Upcomer Glossary

## Core Terms

- **Social Event**: A calendar event that has been explicitly marked for Upcomer by including `social:` in its title. These are the only events the app will display.
- **Upcomer Mode**: The default view of the app. Displays all social events in the next 30 days as a simple chronological list of cards, sorted by soonest first. Shows only the event title and relative time.
- **Day Mode**: The secondary view of the app. Displays social events visually placed on the specific calendar days they occur. Used to quickly see which days have events and which days are free.
- **Relative Time**: A human-friendly way of expressing when an event occurs (e.g. “today”, “tomorrow”, “in 3 days”). This is the primary time format shown in Upcomer Mode.

## Technical & Project Terms

- **Google Calendar Sync**: The process of fetching events from the user’s Google Calendar using the Google Calendar API.
- **Cache**: Locally stored social events on the user’s device. Used to display data instantly when the app is opened.
- **Refresh**: The action of pulling the latest social events from Google Calendar.
- **OAuth Token**: The authentication token used to securely access the user’s Google Calendar data.

## Screens

- **Integration Screen**: The initial screen shown to new users. Prompts them to connect their Google account.
- **Main Screen**: The primary screen of the app that contains both Upcomer Mode and Day Mode.

## Acronyms

- **MVP**: Minimum Viable Product — the initial version of Upcomer with core functionality.
- **FFF**: Fast, Foolproof, Flexible — the guiding principles of this development system.
